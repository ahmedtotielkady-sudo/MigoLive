# MigoLive

تطبيق أندرويد محلي بالكامل (Local-first) مبني باستخدام Capacitor.

- الحسابات والملفات الشخصية والعملات والوكالات وسجلات الألعاب تُحفظ محلياً على الجهاز.
- لا يحتاج التطبيق إلى Backend أو MongoDB أو خادم API.
- تفعيل المالك يتم محلياً من شاشة الدخول بكود المالك المضمّن في نسخة التطبيق.
- إنشاء APK جديد وتحديث التطبيق يتم يدوياً من مشروع Android/Capacitor.

**ملاحظة:** البيانات المحلية لا تتزامن بين أجهزة المستخدمين ولا تنتقل تلقائياً بين النسخ أو بعد حذف بيانات التطبيق.
