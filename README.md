# MigoLive

تطبيق أندرويد محلي بالكامل (Local-first) مبني باستخدام Capacitor.

- الحسابات والملفات الشخصية والعملات والوكالات وسجلات الألعاب تُحفظ محلياً على الجهاز.
- لا يحتاج التطبيق إلى Backend أو MongoDB أو خادم API.
- تفعيل المالك يتم محلياً من شاشة الدخول بكود المالك المضمّن في نسخة التطبيق.
- إنشاء APK جديد وتحديث التطبيق يتم يدوياً من مشروع Android/Capacitor.

**ملاحظة:** البيانات المحلية لا تتزامن بين أجهزة المستخدمين ولا تنتقل تلقائياً بين النسخ أو بعد حذف بيانات التطبيق.


## حدود الوضع المحلي

- لا يعتمد التطبيق على خادم API أو قاعدة بيانات خارجية أو WebSocket.
- الحسابات والرصيد والملفات الشخصية والغرف والرسائل وسجلات الألعاب تُحفظ محلياً على الجهاز.
- الغرف والدردشة في هذه النسخة محلية على الجهاز نفسه؛ لا توفر اتصالاً أو محادثة صوتية مباشرة بين أجهزة مختلفة.
- ألعاب 777 وعاصفة المحيط وعجلة الحيوانات تعمل دون خادم، ويُشارك رصيدها مع محفظة الحساب محلياً داخل التطبيق.
- إزالة تحميل موارد الخطوط الخارجية من شاشة الألعاب تضمن عدم احتياجها للإنترنت.
- البيانات المحلية لا تتزامن بين الأجهزة، وقد تُفقد عند مسح بيانات التطبيق أو إلغاء تثبيته؛ استخدم النسخ الاحتياطي داخل التطبيق إن كان متاحاً.
